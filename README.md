# MargyTube

<p align="center"><img src="art/logo.png" alt="MargyTube" width="220"></p>

Открытый клиент YouTube для Android: лента, поиск, видео, комментарии и плагины.
Написан на Java, интерфейс — Material You 3, видео играет **Google Media3 (ExoPlayer)**,
а данные и потоки приходят напрямую с серверов YouTube — **без API-ключа**.

**[Скачать MargyTube.apk](https://github.com/rybchikdavid-byte/MargyTube/releases/latest)** · Android 8.0+ · ~7 МБ

## Что умеет

- **Лента и поиск** напрямую через внутренний протокол YouTube (InnerTube), без ключа.
  Для аккаунта — персональные рекомендации, без входа — поиск по интересам.
- **Настоящий плеер**: Media3/ExoPlayer с аппаратным декодером. Не веб-обёртка и не
  имитация: видео и звук идут отдельными потоками YouTube и склеиваются в плеере.
- **Вход в Google** через OAuth device flow: код показывается в приложении, пароль
  вводится только на `google.com/device`. Токен хранится на телефоне и обновляется сам.
- **Комментарии**: чтение с YouTube, отправка своего, лайк видео.
- **Оформление**: Material You из системных обоев на Android 12+, шесть акцентов,
  светлая/тёмная/системная тема, три стиля карточек, радиус 0–28 dp, шрифт 85–125 %.
- **Плагины** `.mgtp` (manifest.json + JS) — меняют ленту, экран видео и оформление.
  Плагин **«Полная кастомизация»** уже собран внутрь APK и устанавливается при первом запуске.
- **Выбор региона** — от него зависят выдача и язык названий.

## Вход в Google

1. Настройки → **Аккаунт Google** → **Войти**.
2. Приложение покажет короткий код и откроет `google.com/device`.
3. Введи код на сайте и подтверди доступ. Окно можно закрыть — вход завершится сам.
4. Появится имя канала; лайки и комментарии будут уходить от твоего имени.

Используется публичный OAuth-клиент «YouTube на ТВ», поэтому регистрировать
свой проект в Google Cloud не нужно. Это **неофициальный путь**: Google может
отозвать клиент или поменять правила в любой момент.

Пароль не попадает в приложение. Access-токен и refresh-токен лежат в обычных
SharedPreferences внутри приложения (не в зашифрованном виде).

## Family Link и родительский контроль

Если аккаунт ограничен Family Link, Google сам запрещает комментарии, лайки и часть
данных. Приложение это ограничение **не обходит**: покажет ответ YouTube. Взрослый
аккаунт без ограничений работает штатно.

## Плагины

`.mgtp` — обычный ZIP с файлами в корне:

```
manifest.json
plugin.js        # или classes.dex
icon.png         # необязательно
```

`manifest.json`:

```json
{
  "id": "com.example.myplugin",
  "name": "Мой плагин",
  "version": "1.0",
  "author": "you",
  "description": "Что делает",
  "hooks": ["onApp", "onFeed", "onVideo"]
}
```

Хуки:

- `onApp()` — выполняется при запуске приложения. Может задать всё оформление:
  `margytube.applyStyle({accent, theme, cards, radius, font})`.
- `onFeed(json)` — получает JSON-массив ленты и возвращает изменённый JSON (или `null`).
- `onVideo(id)` — получает id видео и возвращает короткую заметку (или `null`).

Ещё доступны `margytube.get(key)` (`accent`, `theme`, `cards`, `radius`, `font`,
`region`, `account`, `signed_in`) и `margytube.log(...)`.

JS работает в песочнице Rhino: только безопасные стандартные объекты, без `java.*`
и `Packages`, лимит 2,5 секунды, сеть недоступна. Плагин может быть и DEX-файлом
с классом `com.wexresprise.margytube.plugin.MargyTubePlugin`; у такого плагина права
приложения, поэтому ставь только свой код.

Встроенный плагин «Полная кастомизация» меняет акцент по времени суток, ставит
скругление 20 dp, залитые карточки и помечает видео в ленте. Его можно выключить
или удалить на вкладке **Плагины**. Копия для установки вручную —
`MargyTube-Custom.mgtp`.

## Сборка

**GitHub Actions** — `.github/workflows/build.yml` собирает release APK на каждый
push в `main` и кладёт его в артефакт `MargyTube-apk`. Готовый файл — в **Releases**.

**Локально** — Android Studio, JDK 17, Android SDK 35, Gradle:

```
gradle :app:assembleRelease
```

Подпись — `keystore/margytube.p12`, alias `margytube`, пароль `margytube123`
(хранилище и ключ). Ключ лежит в репозитории намеренно: так любой может собрать
и обновить приложение. SHA-256 сертификата:
`A4:ED:67:65:4F:50:63:F9:B4:82:63:28:ED:66:F8:32:21:57:8F:59:83:F7:25:42:78:51:5D:EF:56:89:39:BE`.

## Чего приложение не делает

- Не скачивает видео и не сохраняет потоки на диск.
- Не блокирует рекламу: она приходит в потоке так же, как в обычном клиенте.
- Не обходит блокировки, возрастные и родительские ограничения.
- Не собирает аналитику и не отправляет данные на свои серверы.
- Не использует YouTube Vanced и не встраивает веб-версию сайта.

## Важно понимать

- InnerTube — внутренний протокол YouTube, а не публичный API. Он **неофициальный**,
  может меняться без предупреждения, и его использование нарушает условия YouTube.
- Прямые ссылки на потоки иногда отдают ускоренное воспроизведение (`n`-throttling)
  или блокируются для части сетей. Если видео не играет — попробуй другую сеть.
- Вход через ТВ-клиент Google может быть отозван. Это не взлом аккаунта: пароль
  не запрашивается, доступ можно в любой момент убрать на `myaccount.google.com`.
- Данные и видео принадлежат YouTube и авторам. Приложение только показывает их.

## Структура

```
app/src/main/java/com/wexresprise/margytube/
  MainActivity.java     — лента, поиск, плагины
  PlayerActivity.java   — Media3-плеер, описание, лайк, комментарии
  SettingsActivity.java — аккаунт Google, регион, оформление, плагины
  InnerTube.java        — запросы и разбор ответов YouTube, потоки, комментарии
  GoogleAuth.java       — OAuth device flow и обновление токена
  Prefs.java            — настройки, аккаунт, тема, акценты, шрифт
  plugin/               — .mgtp: манифест, Rhino-песочница, DEX-загрузчик
app/src/main/assets/    — custom.mgtp (встроенный плагин)
plugins/margytube-custom/ — исходники этого плагина
app/src/main/res/       — Material 3 темы, экраны, иконки
keystore/               — ключ подписи
```
